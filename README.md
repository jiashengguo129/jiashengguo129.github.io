# jiashengguo129.github.io

Personal site. Three files: `index.html`, `Jiasheng_Guo_CV.pdf`, and (optional) `photo.jpg`.

## Publish on GitHub Pages
1. Create a public repository named exactly `jiashengguo129.github.io`.
2. Upload `index.html` and `Jiasheng_Guo_CV.pdf` to the repository root.
3. Wait a minute or two, then open https://jiashengguo129.github.io

## Edit
- Photo: add `photo.jpg` to the root, then in `index.html` replace `JG` inside `<div class="photo">` with `<img src="photo.jpg" alt="Jiasheng Guo">`.
- Links: search `index.html` for `TODO` to add the dataset, demo and project page URLs.
- CV: overwrite `Jiasheng_Guo_CV.pdf` with a newer export; the file name must stay the same.
- News: add a new `<dt>` / `<dd>` pair at the top of the News list.
